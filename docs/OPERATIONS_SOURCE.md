# 탈환 작전실: 현재 구현 범위와 원본 연결

이 작업은 11단계 코드 위에 작전실 기본 화면을 추가한 준비 단계입니다. `step`은 11이며 제출 코드와 1~11단계 방어 로직은 변경하지 않았습니다. 실제 운영 원본이 없으므로 12단계 완료나 `S12_SCREEN_MISMATCH` 해결을 주장하지 않습니다.

## 현재 API의 실제 동작

`GET /api/ops`는 현재 항상 HTTP 503과 `operations_source_not_connected`를 반환합니다. 운영 판정·탐지·회수·복구 기록을 읽는 공식 API·형식이 제공되지 않았기 때문입니다. 응답에는 구현된 `RULE_IDS`와 네 분야의 미확인 상태가 들어가며 `summary`와 `records`는 없습니다. 분야별 실행 수·미실행 수·최근 결과·복구 정책 버전은 `null`입니다. 0건·빈 운영 기록·학생 자기 점검을 운영 결과 대신 반환하지 않습니다.

화면 `/ops.html`은 이 상태를 원본 미연결로 표시합니다. 이전 결과가 있었다면 수치와 행을 지웁니다. 실제 원본 조회의 실패와 원본에 기록된 `not_run` 항목은 서로 다릅니다. 원본을 못 읽었다는 이유로 미실행 개수를 계산하지 않습니다.

## 연결 뒤에 사용할 화면용 모델

아래 모델은 이 앱 내부의 어댑터 형식입니다. 운영 엔진의 공식 외부 API 계약이라는 뜻이 아닙니다. 실제 원본 형식을 확인한 뒤 서버의 `readOperationsRecord()`에 읽기·변환을 구현해야 합니다. 브라우저 입력·정적 예제·가상 연습은 원본으로 사용하지 않습니다.

- 입력: `schema: aleph.operations-record.v1`, `source: server_record`, 실제 `checkedAt`, `summary`, `records`.
- 집계: `total`, `recorded`, `notRun`. 행을 재집계해 원본 합계와 다르면 503으로 거부합니다. 공격 차단·허용 건수는 근거 없이 계산하지 않습니다.
- 행: `category`(decision/detection/revocation/recovery), `status`(recorded/not_run), 실제 `outcome`, UTC `at`, 확인된 정수 `policyRevision`, 현재 목록에 있는 `ruleIds`만 허용합니다.
- 판정 결과: allow/deny/step_up. 탐지 결과: observe/propose_revocation. 회수 결과: revoked/failed. 복구 결과: restored/failed. 운영 엔진 원본과의 실제 매핑은 아직 확인하지 못했습니다.
- 미실행 행은 결과·확인 시각·복구 정책 버전이 없습니다. 회수 제안을 회수 완료로, 배포 커밋을 복구 버전으로 바꾸지 않습니다.
- 서버는 명시한 필드만 남깁니다. 메모 본문·계정·기기 식별자·토큰·임의 설명·추가 집계 필드는 공개하지 않습니다.

화면은 HTTP 200의 `aleph.ops.v1` 응답에서 가린 행과 집계를 함께 받아 다시 대조한 뒤 같은 응답의 수치를 표시합니다. 서버가 만든 `domains`의 분야별 실행·미실행·최근 결과·복구 정책 버전도 같은 행으로 검증합니다. 복구 버전은 실제 `restored` 기록의 정책 버전만 사용하고 배포 커밋이나 복구 실패의 버전으로 대체하지 않습니다.

화면의 이번 작전실 API HTTP 상태와 가린 서버 기록 JSON은 한 번의 조회 응답에서 표시합니다. JSON을 보기 위해 다른 시점의 API를 다시 호출하지 않습니다. 503 응답도 같은 규칙으로 표시하며 운영 결과가 없는 상태를 확인할 수 있습니다. 대조 실패·조회 실패에서는 기존 숫자·행·가린 JSON을 지웁니다. 늦게 도착한 과거 응답도 최신 상태를 덮어쓰지 않습니다. 원본 연결이 없는 현재 배포에서 HTTP 200의 운영 결과 표시 경로는 실행되지 않습니다.

## 확인

`node --test test/operations.test.mjs`는 원본 미연결 503, 내부 테스트 기록의 집계 일치, 불일치 거부, 미실행 구분, 민감 필드 제외, 재조회 실패 시 삭제를 확인합니다. 테스트 기록은 로컬 검증용이며 실제 운영 결과가 아닙니다.

자료실에서 작전실 링크를 누르고 운영 결과 다시 조회를 실행하면 원본 미연결과 수치 미표시가 정상입니다. `/api/ops`의 POST는 405로 거부되어야 합니다. 최종 12단계와 41종 공격 방어는 실제 원본 연결·심판 재판정 전까지 미확인입니다.
